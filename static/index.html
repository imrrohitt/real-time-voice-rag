Talk to the assistant

Hold the button, speak, then release. The server converts browser audio to WAV with ffmpeg before Groq STT (raw WebM is often rejected). Install: brew install ffmpeg (macOS) or apt install ffmpeg (Linux). Best: open http://127.0.0.1:8765/ (same server as the API). If you use Live Server on another port, this page auto-targets 127.0.0.1:8765 for API calls.

RAG — upload PDF

Text is extracted with PyMuPDF; scanned pages use Tesseract OCR if little text is found (brew install tesseract). Chunks are embedded with fastembed and stored in a local FAISS index under voice_testing/data/rag/. Voice questions retrieve matching chunks for Groq.
